# Landing page assets

`ledger-satin.jpg` is a decorative asset generated with OpenAI ImageGen for SweepDock on 2026-09-05. It contains no user data. The UI, labels and sample balances are rendered as accessible HTML over the texture. JPEG compressed from the original generated PNG.

Fonts are hosted locally under `../fonts/`, with the original SIL Open Font License for each family. Sources: [Instrument Sans](https://github.com/Instrument/instrument-sans) and [Newsreader](https://github.com/productiontype/Newsreader), served by Google Fonts. No remote font requests are made by the app.
